<b> Abstract </b>

This repository was created as part of the Flax/JAX community week by HuggingFace. The aim of this project is to pretrain a language model using GPT-2 specifically for the Tamil language, using a causal language modeling (CLM) objective. The pretrained model is published on the HuggingFace Hub, and the accompanying space demonstrates it alongside other Tamil language models.

Link to model: <a href="https://huggingface.co/abinayam/gpt-2-tamil">abinayam/gpt-2-tamil</a>
