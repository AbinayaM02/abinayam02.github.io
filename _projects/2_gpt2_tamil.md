This project was created as part of the Flax/JAX community week by HuggingFace. The aim was to pretrain a language model using GPT-2 specifically for the Tamil language, using a causal language modeling (CLM) objective.

- [Pretrained model on HuggingFace](https://huggingface.co/abinayam/gpt-2-tamil)
- [Tamil Language Demos space](https://huggingface.co/spaces/flax-community/TamilLanguageDemos)
