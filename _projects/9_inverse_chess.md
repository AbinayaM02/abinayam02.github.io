<b> Abstract </b>

Inverse chess is a game with a pre-defined start position, an end position and arbitered moves chosen amongst a set of possible moves, played between two opponents on a chess board. This differs from normal chess in that it is played backwards in time, where the objective is to reconstruct the pre-identified start position from the pre-identified end position. While the pieces used in the game are essentially the same as those of regular chess, the moves they make are reversed. Since the state-space of this game is much larger in the potential moves, an arbiter is used to validate possible moves that one player might choose.
